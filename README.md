# Enterprise Buddy

Enterprise Buddy is a desktop AI companion designed for enterprise workers.

The companion is represented by a virtual pet named Byte.

Unlike traditional productivity dashboards, Byte's wellbeing reflects the user's enterprise work habits and attention to responsibilities.

Examples:

- Unread messages make Byte hungry.
- Unanswered emails make Byte hungry.
- Overdue tasks make Byte worried.
- Meeting overload makes Byte tired.
- Completing important work makes Byte healthy and happy.

The goal is to create emotional engagement around workplace productivity.
